# Social-Link-Profile---Frontend-Mentor-Challenge
Exercício de prática HTML e CSS para criação de uma tela de links para redes sociais responsiva.

Este é um desafio do [Frontend Mentor]([https://www.frontendmentor.io](https://www.frontendmentor.io/challenges/social-links-profile-UG32l9m6dQ)), feito para praticar HTML e CSS. 
O objetivo é recriar um componente de perfil social responsivo.

## 🚀 Tecnologias usadas

- HTML5
- CSS3
- Responsividade com Flexbox

## 📱 Resultado

O projeto foi feito pensando em dispositivos móveis e desktops.
